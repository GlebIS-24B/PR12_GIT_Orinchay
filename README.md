## Описание программы

**SmartBudget** — это легковесное консольное приложение для контроля личных финансов.
Программа помогает *записывать* ежедневные расходы, ~~забывать~~ анализировать траты по категориям и строить простую статистику. 📊

Эти инструкции предоставят вам копию проекта и помогут развернуть его на вашем локальном компьютере для тестирования.

### Необходимые условия

Для запуска программного обеспечения вам потребуется:

- Установленный интерпретатор **Python 3.9+**
- Менеджер пакетов **pip**
- Система контроля версий **Git**

Проверить наличие компонентов можно командами в терминале:

```

python --version
pip --version
git --version

```

### Установка

Пошаговая инструкция для запуска проекта.

**Шаг 1.** Склонируйте репозиторий с вашим кодом:

```

git clone https://github.com/ваш_никнейм/PR12_GIT_Orin.git
cd PR12_GIT_Orin

```

**Шаг 2.** Создайте и активируйте виртуальное окружение:

```

python -m venv venv
venv\Scripts\activate      # Для Windows
source venv/bin/activate   # Для Linux / macOS

```

**Шаг 3.** Установите необходимые библиотеки:

```

pip install -r requirements.txt

```

**Шаг 4.** Запустите главный скрипт программы:

```

python main.py

```

Проверьте, что всё работает, запросив версию программы:

```

python main.py --version

```

## Структура репозитория

| Папка/файл | Описание |
|------------|----------|
| `main.py` | Точка входа, интерфейс командной строки |
| `finance/` | Логика расчетов и работа с базой данных |
| `data/` | Папка для хранения файлов с историей трат |
| `tests/` | Юнит-тесты для проверки корректности кода |

## Использование

Пример программного добавления новой траты из кода:

```python
from finance import add_expense

# Добавляем расход на сумму 67 рублей
add_expense(amount=67, category="Продукты", comment="Покупка в супермаркете")
print("Расход успешно записан ✅")
```
